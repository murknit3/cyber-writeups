# Offensive Security

This section contains methodology-focused offensive security write-ups from labs and authorised testing environments.

## Areas covered

- **Web applications** — recon, access control, input handling and application logic.
- **Active Directory** — enumeration, privilege paths and lateral movement in lab environments.
- **Hack The Box** — selected machine write-ups focused on reasoning and technique selection.

Write-ups here are intended to explain the process and lessons learned rather than simply publish flags or answers.
