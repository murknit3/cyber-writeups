# Cybersecurity Write-Ups

This is my working archive of investigations, labs and technical notes.

The goal is not to collect answers. Each write-up records **how I approached the problem**, what telemetry mattered, where I pivoted, and what I learned from the investigation.

## Main areas

- **Blue Team** — SOC investigations, Splunk, alert triage and threat hunting.
- **DFIR** — Windows telemetry, endpoint evidence and network forensics.
- **Offensive Security** — web, Active Directory and machine write-ups.
- **Knowledge Base** — concise references I can reuse during investigations.

> **Publishing rule:** Never publish active exam answers, private client data, credentials, tokens, personal information, or anything covered by an NDA.
